# File-Sorter-Python
## Overall Description
This is a simple file to folder sorter for Linux Desktop, made in Python
The system allows the user to choose which folder they would like to sort and organises in term of...

Folder Name:   |     Extension
---------------------------------------------
images               .png, .jpg, .webp

documents            .pdf, .docx, .txt

coding               .py.java.c

videos
.mp4
.mp3
